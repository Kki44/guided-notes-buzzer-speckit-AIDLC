# 核心流程調整任務 v3.0

本次核定範圍見 [SRS](spec.md)，細部分工與執行進度見 [實作計畫](../../docs/superpowers/plans/2026-11-26-core-alignment.md)。本文件取代先前已被撤銷的功能任務。

1. 匯入子功能：分頁解析、預覽、確認重讀與建立活動。
2. 活動與組別：單向狀態、批次／逐組、準備刪組、活動網址恢復。
3. 作答子功能：直接入組與重新選組、版本防誤送、最後有效答案、相同答案不計時、重送。
4. 同步與結果：同組同步、八組並行、時鐘倒退序號、固定第一名與學生隱私。
5. 回填子功能：預覽取消／確認、原格保護、字面值、未知結果及重啟核對。
6. 交付：規格／圖表／程式一致、自動測試、人工驗收清單、README、Git commit。
