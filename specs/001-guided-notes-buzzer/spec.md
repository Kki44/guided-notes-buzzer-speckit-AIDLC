# 軟體需求規格書 SRS v3.0.1

核定日期：2026-11-26。此版取代先前功能規則；以本文件及本次執行計畫為準。

## 1. 目的與使用者
老師匯入 Guided Notes，建立組別，一次開放全部題目；學生按組別自由選題提交。活動結束後產生固定順位，老師預覽並確認將搶答成功答案回填 Google Sheets。

## 2. 子功能拆分
匯入預覽與活動建立、組別設定與加入、答案提交與同步、截止結算與角色公開、Google Sheets 同步與回填、活動恢復與權限。

## 3. 核心需求
- FR-01：老師使用環境變數管理密碼登入；老師與學生使用獨立網址，沒有互跳導覽。所有寫入驗證角色、CSRF、活動／組別範圍及輸入，錯誤以繁體中文回報。機密只從環境變數讀取，不寫入程式、日誌、文件或資料庫。
- FR-02：老師貼原生 Google Sheets HTTPS 連結，讀取分頁，選定單張工作表後預覽題號、題目及答案格，確認時才建立含名稱的活動。預覽綁工作階段，20 分鐘失效；確認重新讀表核對內容，變動／過期／取消不得建立活動。解析唯一「題號／題目／作答」表頭，保留合併格與小題的定位；相容既有 Qn／{{Qn}} 標記。答案寫入動態辨識的格位，不硬編碼座標。
- FR-03：準備 ready（DRAFT）→ open（OPEN）→ closed（CLOSED），不可逆。開放需要至少一題與兩組，全系統最多一場 open。結束後不能重開、重新開始或同場換表；下一份表另建活動。重複截止回相同結果。
- FR-04：準備階段可逐組命名建立或輸入 1–100 組整批產生；同場名稱不可重複。曾有學生加入即永久禁止該活動整批重建，即使之後刪除該組亦不解除。刪組僅準備階段可用，撤銷該組入組狀態。開始後組別設定唯讀。
- FR-05：學生輸入活動識別碼，取得該活動組別後選組加入；不需組別加入碼與老師審核。可重新選組，只移動本人，原組答案保留。伺服器遞增 membership version，舊分頁及 A→B→A 的舊提交均拒絕；學生需確認最新組別再作答。
- FR-06：已加入組員都能在 open 任選題提交／修改。同組同題保留最後有效答案；trim 後非空、最多 4,000 字，無效 Unicode 拒絕。相同有效答案以新 receipt 再送回 409「答案未變更，無須重新提交」，不改提交、序號與時間。相同成功 receipt 重試回原結果；同 receipt 不同內容拒絕。
- FR-07：有效提交序號在 SQLite 寫入交易內配發；截止與提交序列化。每題依各組最後有效 sequence 升冪排名，不受同時間或時鐘倒退影響。時間為伺服器記錄，老師以台灣時區至毫秒查看。closed 拒絕新提交，但成功 receipt 可重取原回應。
- FR-08：結束每題第一名直接取得搶答成功資格，無人提交則無成功組別。不提供正誤判定、遞補或更正得主。搶答成功答案不等於正確答案；老師人工檢查不改系統結果。
- FR-09：老師看各題全部答案、提交時間及結束後完整順位。學生開放前後只能看本組答案及作答狀態；closed 額外顯示成功組別名稱及本組名次，不提供其他組答案、時間、順位或正確答案欄位。API 本身實施隔離。
- FR-10：約每秒輪詢伺服器快照，返回可見頁面立即同步；GET 逾時會重試。作答卡不拉長其他卡；送出後標示已作答、保留答案預覽並提供修改入口。同組其他工作階段同步本組有效答案。
- FR-11：Google Sheets 同步與回填僅 closed 老師可用。先預覽題號、工作表、答案格、原值及目標答案，明示未經正確性判定。老師確認才寫入，取消不寫，不提供改選其他組答案。確認時重新檢查預覽摘要、題目錨點、保護與原值，任何衝突停止整批。答案以純文字批次寫回；未知結果保存待核對批次，重讀核對後才繼續，不盲目重送。無人提交的格子不寫。
- FR-12：老師可複製活動專屬網址，直接進入／重新整理恢復該場資料；不存在顯示錯誤，不建立替代活動。保留老師活動清單便於選擇與複製網址。SQLite 保存活動、加入、答案、順位與回填資料，搶答核心不依賴 Google 即時可用性。
- FR-13：升級不自動刪除既有資料（老師明確確認刪除活動依 FR-14）；舊判定欄位、換組申請及輪次快照留存但不新增／寫入。不提供舊輪次面板或查閱 API，僅保留資料庫相容資料。移除重開、判定、換組審核與額外提交進度統計入口；舊寫入 API 不可繼續執行。

## 4. 非功能需求
單一 Flask 程序與 SQLite WAL；無新套件需求。機密只透過環境變數；所有 Google 錯誤需去除敏感細節。靜態檔依修改時間加版本，頁面／API 不快取。

## 5. 驗收
匯入預覽取消／變更、兩組提交修改／同答案拒絕、時鐘倒退、同組多視窗、換組舊分頁拒絕、截止後禁止提交、學生隱私、預覽取消不寫／確認原格衝突、重啟與舊資料保存均須有正常及邊界測試。
